## 19-1 탭이 하던 일과 치르던 값

계열 탭은 강화 페이지를 416px로 줄여 **스크롤을 없앴다.** 18단계 보고서가 그것을
두 줄을 감수한 근거로 적었다. 그런데 그 계산에는 값이 한쪽만 들어가 있었다 —
탭은 여섯 축 중 **넷을 항상 감춘다.**

골드를 어디에 쓸지 고르는 화면에서는 무엇이 있는지가 곧 필요한 정보다. 세 번
눌러 비교하는 값이 한 번 훑어 내리는 값보다 크다. 스크롤은 손가락 한 번이지만
탭은 **화면에 없는 것을 기억하고 있어야** 쓸 수 있다.

```
탭 방식   강화 페이지 416px, 스크롤 없음, 한 번에 2축   (4축은 안 보임)
목록 방식 강화 페이지 1212px, 스크롤 628px, 6축 전부   (탭 줄 88px 회수)
```

탭 줄이 한 줄로 줄면서 층위 문제도 없어졌다. 남은 기준은 재화 하나뿐이다.

## 19-2 목록 순서와 높이

지시한 순서 그대로다. 계열 배열의 순서가 곧 화면의 순서이고, `Specs` 순서와
같아야 트랙 인덱스와 화면 순서가 어긋나지 않는다.

```
y=  -12   [공격]          <- 머리글 62px
y=  -84   공격력 강화      Lv.116
y= -242   공격속도 강화    Lv.32   MASTER
y= -418   [치명타]
y= -490   치명타 확률      Lv.97   MASTER
y= -648   치명타 피해      Lv.114
y= -824   [생존]
y= -896   체력 강화        Lv.68
y=-1054   체력 회복        Lv.45   MASTER
                                     총 1212px
```

| | 높이 |
|---|---|
| 행 6개 + 위 여백 | 960px |
| 계열 머리글 3개 | 3×(62+10) + 2×18 = **252px** |
| **합계** | **1212px** |
| 스크롤 영역 (설계 1080×1920 기준) | 584px |
| 스크롤 범위 | 628px |

배치와 높이 계산이 **같은 코드를 지난다**(`WalkEnhanceList`). 따로 두면 머리글
여백을 한쪽만 고쳤을 때 Content 크기와 실제 내용이 어긋나고, 화면에서는
"마지막 줄이 안 보인다" 또는 "아래가 텅 빈 채로 스크롤된다"로만 나타난다.

## 19-3 머리글은 얇게 — 탭으로 만들지 않았다

지시가 "그룹 구분이 필요하면 얇은 카테고리 헤더 정도만"이었다. **넣었다.**

여섯을 아무 표시 없이 잇는 것은 17단계 소감의 "강화 목록이 안 나뉜다"로 그대로
돌아가는 길이다. 머리글은 252px을 더 스크롤하는 값을 치르고 훑을 때의 기준점을
준다.

**행의 절반도 안 되는 한 줄**이다(62 대 144). 배경판도 버튼도 없고 색은 흐리다.
머리글이 행만큼 두꺼우면 목록이 아홉 줄로 읽히고, 그러면 나누려던 여섯이 오히려
더 길어 보인다.

버튼을 안 다는 데는 이유가 하나 더 있다 — 행 아이콘 검사가 버튼 유무로 행과
머리글을 가르므로(`VerifyRowIcons`), 버튼이 있으면 "아이콘 없는 행"으로 잡힌다.
남은 포인트 머리글에서 이미 한 번 겪은 자리다.

---

## 검사도 함께 뒤집었다

18단계의 `VerifyPagesFitWithoutScrolling`은 **모든 페이지**가 화면에 들어가는지
봤다. 이제 강화는 넘치는 것이 설계라 그 검사를 그대로 두면 매 빌드가 경고를
내고, 곧 아무도 안 읽는 경고가 된다.

`VerifyPageHeights`로 바꿔 **성장·전직만** 지킨다. 그 둘은 각각 두 축과 안내
하나뿐이라 넘칠 이유가 없고, 넘겼다면 누가 줄 높이나 축 수를 건드린 것이다.
화면에서는 어느 쪽이든 "스크롤이 생겼다"로만 보이므로 의도를 코드에 적어두고
빌드가 대조한다.

행 수 검사도 함께 고쳤다 — 강화 페이지의 자식이 6개에서 **9개**(축 6 + 머리글 3)가
됐다. 그대로 뒀으면 매 빌드가 실패했을 것이다.

`UpgradeCategoryTabs.cs`는 지웠다. 씬·프리팹 어디에도 GUID 참조가 남아 있지
않은 것을 확인하고 스크립트와 .meta를 함께 지웠다.
