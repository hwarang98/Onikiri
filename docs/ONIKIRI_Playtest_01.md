## 2. Safe Area 실기 확인

에디터의 `Screen.safeArea`가 신뢰할 수 없다는 것이 8단계에서 드러나
(1080×1920 화면에 960×2566을 반환) 실기 확인이 필요합니다.

| 항목 | 결과 |
|---|---|
| 노치/펀치홀이 있는 기기인가 | ☐ 예 ☐ 아니오 |
| 상단 골드/스테이지 표시가 가려지는가 | ☐ 예 ☐ 아니오 |
| 하단 제스처 바가 강화 버튼을 가리는가 | ☐ 예 ☐ 아니오 |
| 배경이 화면 끝까지 그려지는가 (검은 띠 없음) | ☐ 예 ☐ 아니오 |
| 가로 폭이 잘리지 않는가 | ☐ 예 ☐ 아니오 |

마지막 두 항목이 "예"여야 정상입니다. **월드는 안전 영역을 무시하고 화면 끝까지
그리고, UI만 안으로 들어오는 것**이 설계입니다.

문제가 있으면 스크린샷을 찍어주세요.
