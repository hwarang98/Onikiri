## 2b-1 폰트 위계 — 38단계의 Demote를 나머지 화면에 쓸었다

캐릭터 화면과 같은 규칙을 스킬·퀘스트·장비·동료 패널과 전직 카드에 적용했다.
행/카드의 글자는 전부 캡션(33), 44로 남는 것은 **동사와 머리글**뿐이다:

- 스킬 행: 이름·해금 레벨·쿨다운 → 33. 머리글 "발도 오의"와 자동 시전 토글 = 44
- 퀘스트 행: 제목·진행 숫자·보상 → 33. **받기 버튼만 44** — 목록에서 유일하게
  눌리는 동사다. "완료" 배지는 33 — 상태는 동사와 크기가 갈려야 한다.
  서브탭(일일/반복/업적)·리셋 타이머 → 33
- 장비 카드: 등급 이름·배수·슬롯·단련 Lv → 33. 단련/등급업 버튼의 **제목 44 + 비용 33** —
  같은 크기로 두면 버튼 안에서 무엇이 동사인지 읽히지 않는다
- 동료 카드: 이름·DPS·역할·레벨 → 33. 버튼 제목 44 + 비용 33
- 전직 카드: 경지 이름·배수 → 33. 진화 버튼 제목 44 + 비용 33 —
  이 카드에서 크게 말하는 것은 글자가 아니라 초상이다

## 2b-2 톤 통일 — 색의 출처를 하나로

스텝별로 따로 태어난 패널들이 각자 들고 있던 값을 UiSkin으로 회수했다.

| 값 | 이전 | 이후 |
|---|---|---|
| 본문/흐림 텍스트 | 빌더 6곳에 사본 | `UiSkin.Text` / `UiSkin.TextDim` |
| 보석 버튼 청 | 장비·동료 (0.42,0.56,1.00) / **전직만 (0.55,0.66,1.00)** | `UiSkin.GemAction` 하나 — 전직 버튼의 편차가 실제로 잡혔다 |
| 완성 금 | 강화 MASTER·전직 최종이 각자 #FFD34D | `UiSkin.Gold` |
| 퀘스트 진행바 트랙 | 저만 #2A253C | `UiSkin.BarTrack` (#181424) — "바의 빈 부분은 어디서든 같은 어둠" |

강조색 규칙을 UiSkin 주석에 박았다: **적(위험/배지)·금(완성)·청(보석)** 셋뿐.
재화·상태 색(EXP 옥색·보석 청·골드)은 건드리지 않았다.

## 2b-3 화지 벚꽃 실루엣 — 25단계에 보류한 것

`BackdropTextureBuilder.BuildSakuraSilhouette`가 240x100 벚가지 한 장을
결정론적으로 굽는다(본가지 베지어 + 처지는 잔가지 5 + 꽃송이 = 중심을 비운
5~6꽃잎, 씨드 39). 흰색으로 굽고 배치 틴트가 최종 색 — 멀티플라이 함정이
구조적으로 없다(곱할 바탕이 흰색).

- 배치: **오른쪽 위 모서리, 2배 정수 배율(480x200)**. 왼쪽 위는 제목의 자리다
- 틴트 `#312A44` = PanelInk(#221D30)에서 반 톤 — 화지 결(10%)보다 약간 진한
  정도라 시선이 머물면 보이고 훑을 때는 사라진다. 실기 캡처로 확인
- `AddSakuraBranch` 헬퍼 하나를 8개 바탕이 공유: 성장 공용 백드롭 + 스킬/퀘스트/
  장비/동료 + 스탯/재선택/설정. **같은 자리에 같은 가지**라 탭을 오가도 가지가
  이어져 보인다 — "한 앱"의 그림
- 행 카드가 덮는 부분은 그냥 안 보인다. 배경 모티프는 가려져도 거짓말이 아니다

## 2b-4 경지 상승 연출 — 가장자리 빌림을 걷어내고 세 박자로

33단계는 귀참의 ScreenFlash를 빌려 썼다. 그 연출은 **가운데를 일부러 비운다**
(귀참은 무엇이 죽었는지 보여야 한다) — 그래서 경지가 올라도 가장자리만 살짝
붉었고 캡처에서 안 보였다. 경지 상승은 반대로 **그 순간 화면의 유일한 사건**이라
가려도 된다:

```
정지   HitStop 0.40초. 전투가 멎고 이 순간만 남는다
점멸   사무라이가 먹빛 실루엣 <-> 원색 3회 (0.07/0.05초)
백광   EvolveFlash — 전면 흰판이 정점(α1.0)에서 시작, 0.08초 유지,
       0.45초 걷히면 새 모습이 서 있다. 꽃잎 5다발은 이때 —
       정지가 정확히 이 시점에 풀려 꽃잎이 곧바로 날린다
```

- 신규 `EvolveFlash`(런타임)·빌더는 `EvolutionContentBuilder.BuildEvolveFlash` —
  캔버스 직속 맨 뒤, 꺼진 채 저장, Awake는 알파만 비움(ScreenFlash의 첫 시전
  삼킴 규칙 그대로)
- 전부 unscaled. 자기가 건 정지 속에서 돌므로 코루틴 대기도 Realtime
- 기존 엣지 번쩍(ScreenFlash)은 백광 뒤의 여운으로 남겼다. 히트스톱/timeScale
  규칙은 23단계 그대로 — 게임플레이는 건드리지 않는다
- 백광이 없는 씬(빌더 전)이면 33단계 연출로 폴백
- `evolve_flash.gif` (귀장→데몬사무라이, 실기 52프레임)

## 2b-5 전직 초상 정렬 — "미세 넛지"가 아니라 계통 버그였다

실기 실측(티어 카드 7장 픽셀 판독): 로닌만 발선이 맞고 무사 −44 / 검객 −64 /
검귀 −69 / 귀장 −64 / 데몬 −40px(원본 px) **떠 있었다.**

원인은 아트 여백이 아니라 **`Image.preserveAspect`의 피벗 함정**: preserveAspect는
남는 공간을 박스 가운데가 아니라 **rectTransform 피벗으로** 나눈다. 초상 피벗이
(0.5, 1)이라 줄어든 세로가 전부 아래로 남고 셀이 박스 위 모서리에 붙는다.
33단계 코드는 "셀은 박스 가운데 그려진다"고 가정했다 — 정사각 셀(로닌 96x96)만
우연히 맞았고, 가로로 긴 셀 넷의 오차 `(박스높이−표시높이)/2 × 확대`가 실측
44~69px과 정확히 일치했다.

수정: `feetFromTop = zoom × (1 − 발선) × 표시높이` (가운데 항 삭제). 재실측
결과 **일곱 티어 전부 발선 편차 0px** (`awaken2_t0~6.png`). 팩별 넛지 표는
잔차 마감용으로 만들어 뒀지만(`PortraitNudgeOf`) 전부 0으로 남았다 — 계측이
잡은 것을 손으로 덧대지 않는다.

## 2b-6 잔챙이

### 일일 리셋 UTC 자정 → KST 새벽 4시

- `QuestSystem.QuestDayOf(utc) = (utc + 5h).Date` — KST 04:00 = UTC 19:00이
  퀘스트일 경계. 정적 순수 함수라 테스트가 씬 없이 검사한다
- **세이브 필드 그대로.** 옛 마커(UTC 자정 날짜)의 퀘스트일은 실제 마지막 리셋의
  퀘스트일보다 뒤일 수 없어(자정+5h는 같은 날짜) **건너뜀 경로가 없다** —
  `DailyReset_LegacyMidnightMarkerNeverSkips`가 24시간 전수로 고정. UTC 19시
  이후 저장된 세이브만 로드 직후 리셋이 한 번 오는데, 새 규칙에서 이미 새
  퀘스트일이므로 이중이 아니라 경계 이동이다
- 타이머는 `NextResetUtc` 기준 — 실기에서 UTC 19:00 경계에 정확히 리셋 + 이후
  "초기화까지 23:57" 확인
- 기기 시계 조작 방어는 여전히 범위 밖(서버 없음, 수익화 단계 몫)

### "오의 20회" 일일 — Lv.10 전 대체

`QuestRow.DrawIfLocked`: 일일 + SkillCasts 지표 + 레벨 < `SkillCatalog.PanelUnlockLevel`
이면 **"오의 미개방" + "Lv.10"**으로 그린다(진행바 0, 받기 숨김). 행을 통째로
숨기지 않는 이유는 LockedTab과 같다 — 자리가 사라지면 오의를 열었을 때 일일
보상이 늘어난 것을 알 방법이 없다. 문구는 대장간의 "미개방" 글자를 재사용.
실기 확인: `after_quest_locked.png` (Lv.5 재현).

### 보스 라벨

"보스 도전"(파밍) / "처치 n/n"(할당) / 스테이지 칩 모두 실기 캡처에서 정상.
글리프는 UIStrings 기존분으로 커버 — 조치 불요.

### (선택) 캐릭터 탭 = 현재 경지 초상

글리프 교체 1순위로 적어뒀던 인물 심볼을 **현재 경지 초상**으로 바꿨다.

- `CharacterTabPortrait`(신규 런타임): 탭 아이콘 자리의 RectMask2D 칸 안에서
  초상을 원본 2배로, **머리선을 칸 위에 맞춰** 그린다(다리는 마스크가 자른다 —
  초상(portrait)이라는 말 그대로). 정렬 실측은 전직 카드와 같은 헬퍼
  (`MeasurePortraitBounds`, 머리선 측정 추가)를 공유
- LockedTab과 한 이미지를 놓고 싸우지 않는다 — 캐릭터 탭의 글리프는 빌더가
  비우고(normalIcon=null) 초상은 전용 이미지. 경지가 오르면 탭의 "나"도 바뀐다
- 초상이 안 구워진 씬에서는 인물 글리프 유지(경고 로그)

## 곁들여 잡은 것 둘

### "□전 중" — 34단계부터 깨져 있던 글리프

before 캡처에서 동료 카드가 "□전 중"인 것을 발견 — PetRow가 런타임에 조립하는
"출전 중"의 **'출'이 UIStrings에 없어** 아틀라스에 안 구워져 있었다(34단계 누락,
지금까지 아무도 못 봄). "출전 중"·"레벨업"을 UIStrings에 올리고 차셋(343자)과
두 아틀라스를 재구움. 런타임 조립 문구는 반드시 UIStrings에 든다는 규칙의 네
번째 사례다(보스 이름 3회에 이어).

### 캡처 리그 수리 — 3비율 실기 캡처 복구

`GameViewSizes.Select`가 6000.5에서 True만 반환하고 적용은 안 되던 것(38b) —
**`UnityEditor.PlayModeWindow.SetCustomRenderingResolution` + GameView
`Repaint()`**로 실제 적용됨을 확인. 9:16(1080x1920)/9:19.5(1080x2340)/
9:21(1080x2520) 실기 캡처 복구(`ratio_*.png`), 상단바 1행·행 카드·탭바 전부
앵커대로. 다음 스텝부터 비율 검증을 실기 캡처로 되돌릴 수 있다.
